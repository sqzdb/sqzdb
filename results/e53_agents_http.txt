E53 over HTTP: demos/agents (a database per agent, Go) vs PocketBase 0.40.5 with one shared memories collection (agent field + index), 2026-10-17
Load tool: demos/agents/bench. 2,000 agents x 20 memories spawned from 16 clients; then random agents write one memory and recall the newest 10;
then 100 agents forgotten (sqweezdb: delete the directory; PocketBase: list the agent's records and delete each). No fsync per commit on either side;
the demo opens each agent with log.syncDelay 1s and log.threadsIdleAfter 300ms.
