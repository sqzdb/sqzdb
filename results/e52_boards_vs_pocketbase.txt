E52: demos/boards (multi-tenant task board, Go) on sqweezdb vs the same app on PocketBase 0.40.5, 2026-10-17
Load tool: demos/boards/bench. 10 orgs x 20 members, HTTP on loopback, both servers with no fsync per commit
(sqweezdb Visible durability; PocketBase SQLite WAL + synchronous=NORMAL). Each run starts from an empty data directory.
Note: in the throughput runs sqweezdb inserts ~12x more cards than PocketBase in the same seconds, so the realtime
'memory' figures are not comparable; the equal-fill run at the end is the memory comparison.
